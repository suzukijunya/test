# 🐱 nyasu（ニャス）

ju**nya**（じゅんや）＋ a**su**ka（あすか）から生まれた、ふたりのためのアプリ。

カップルのための管理アプリ（React + TypeScript + Vite）。スマホでもPCでも使えます。

## 機能

| 画面 | できること |
| --- | --- |
| 🛋️ ふたりのおへや | 黒ネコが住むおへや。ふたりで活動するとコインがたまり、飾り（12種）を買って部屋に飾れる。ランク付き |
| 🏠 ホーム | おへやのイラスト、付き合って何日目か、近づく記念日のカウントダウン、行きたいお店・タスク・制作中Vlogのサマリー |
| 📅 カレンダー | ふたりの予定を月表示。予定ごとにコメントでやりとりできる（Googleカレンダーへの追加リンク付き）。ローカル版ではGoogleカレンダーの共有カレンダーとAPI連携（予定の追加・削除、共有カレンダー作成とパートナー招待） |
| 📝 メモ | ふたりの共有メモ（ピン留め）。旅行の持ち物、欲しいものなど |
| 🔔 更新履歴 | 「あすかが予定を追加しました」のように、相手の更新がホームに表示される |
| 📝 やりたい | **行きたいお店**（ジャンル・住所・URL・Googleマップリンク、「行った」記録）と**タスク**（担当・期限・カテゴリ）の管理 |
| 🎂 記念日 | 誕生日・記念日の登録（毎年繰り返し、2/29対応）、年齢/◯周年の自動表示、付き合って100日ごとの節目、Googleカレンダーへの毎年予定として登録 |
| 🎁 お祝い準備 | 記念日ごとの準備プラン：テンプレート付きやることリスト、プレゼント候補と予算管理、予約・当日の流れメモ、サプライズ表示 |
| 💭 質問ゲーム | 今日の質問（毎日1問）＋好きなときにもう1問。自分の答えと相手の答えの予想を入力し、ふたりとも答えたら答え合わせ。的中数と答えの一致率を記録 |
| 🎬 Vlog | 企画→撮影→編集中→公開済のステータス管理、撮影日/公開日、タグ、撮影リスト（撮りたいカット）、YouTubeサムネイル自動表示 |
| ⚙️ 設定 | 二人の名前・付き合った日、Google連携設定、データのエクスポート/インポート |

## 公開版（ふたりで共有）

claude.ai の Artifact として公開しています: https://claude.ai/artifact/4SDsHQtGVY8eXxNXwn5hid

- データはクラウドに保存され、開いている二人の間でリアルタイムに同期されます
- パートナーは、ページの共有メニューからメールアドレスを **編集者** として招待します（claude.ai アカウントが必要）
- サプライズにしたお祝い準備は、作った人にだけ表示されます
- Artifact 上では Google ログインが使えないため、予定はアプリ内のカレンダーで共有し、各予定の「Googleカレンダーに追加」リンクから自分のカレンダーに登録します
- **Googleカレンダーの取り込み**: claude.ai の「設定 → コネクタ」で Google Calendar を追加すると、カレンダー画面の「今すぐ同期」で自分の予定（1週間前〜2か月先）を取り込み、ふたりのカレンダーに表示できます。予定名を隠して「予定あり」だけ共有することもできます。一度同期した端末では、開いたときに自動で同期します

公開用ファイルのビルド:

```bash
npm run build:artifact   # dist-artifact/futari-note.html
```

## 起動

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # ユニットテスト
npm run build    # 本番ビルド（dist/）
```

## Googleカレンダー連携の設定

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「APIとサービス」→「ライブラリ」で **Google Calendar API** を有効化
3. 「OAuth 同意画面」を設定（テスト中は自分とパートナーのGmailを「テストユーザー」に追加）
4. 「認証情報」→「OAuth クライアントID」→ 種類 **ウェブアプリケーション** を作成し、
   「承認済みの JavaScript 生成元」に `http://localhost:5173`（公開時はそのURL）を追加
5. 発行されたクライアントIDを、アプリの **設定** 画面に入力（または `.env.local` に `VITE_GOOGLE_CLIENT_ID=...`）
6. **カレンダー** 画面で「Googleでログイン」→「カレンダー設定」から
   - 新しく「ふたりのカレンダー」を作ってパートナーのGmailを招待する、または
   - パートナーから共有されたカレンダーを選ぶ

二人とも同じ共有カレンダーを選べば、お互いの予定が同じカレンダーに表示されます。

## データの保存について

公開版（Artifact）ではクラウドに保存されます。ブラウザで直接開いたローカル版では、データ（Todo・記念日・お祝い準備・Vlog）は、現在は**各端末のブラウザ（localStorage）**に保存されます。
パートナーの端末と内容をそろえたい場合は、設定画面のエクスポート/インポートを使ってください。

リアルタイムに二人で同じデータを編集するには、Firebase（Firestore + Authentication）などのバックエンドを
追加するのが次のステップです。データアクセスは `src/store.tsx` に集約しているので、そこを差し替える形で対応できます。

## 構成

```
src/
  App.tsx              ルーティング・ナビゲーション
  store.tsx            アプリデータの状態管理（localStorage 永続化）
  types.ts             データ型
  lib/
    dates.ts           日付計算（次の記念日、何日目、100日節目）
    upcoming.ts        記念日一覧・お祝いプランのテンプレート
    googleCalendar.ts  Google Identity Services + Calendar API v3
    useGoogle.tsx      Googleログイン状態
    youtube.ts         YouTube URL → サムネイル
    cloudSync.ts       Artifact の db capability との同期
    questions.ts       質問ゲームの問題集
    game.ts            質問ゲームの進行・採点
    activity.ts        更新履歴
    room.ts            おへやのコイン・飾り・ランク
    googleSync.ts      Google Calendar コネクタからの予定の取り込み
    useGoogleSync.tsx  同期の実行・自動同期・エラー表示
  components/art/      黒ネコとおへやのイラスト（SVG）
  pages/               各画面
```
